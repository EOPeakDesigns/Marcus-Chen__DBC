# Assets required for production

Add these files to this folder before deploying:

| File | Purpose |
|------|---------|
| `Owner.png` | CEO portrait (square, ≥ 400×400 recommended) |
| `MYQR.png` | QR code image shown in the QR modal |

PWA icons are generated into `icons/favicon/png/`:

```bash
npm run icons
```

Commit the generated PNGs with your repository.
